# 工具搜索

对应同一搜索页的三个设计状态：初始 [112:25](https://www.figma.com/design/UQoyHz02FJeU7jbvglW0jG/?node-id=112-25)、结果 [112:79](https://www.figma.com/design/UQoyHz02FJeU7jbvglW0jG/?node-id=112-79)、无结果 [116:205](https://www.figma.com/design/UQoyHz02FJeU7jbvglW0jG/?node-id=116-205)。本次通过 Chrome 浏览器逐个链接读取、查看390×844画面。

模块位置按设计像素估算：头部与搜索区0—168；初始状态在168以下显示最近搜索标签，底部提示“输入关键词，快速找到需要的工具”；结果状态在168以下显示数量与相关度说明，首卡约194开始，卡片宽358、设计高度约88，后续卡片按正常流滚动；无结果状态约264开始为放大镜、提示和“清空并重试”。实际实现将描述文字提升到至少20rpx，长描述自然换行、卡片随内容增高。头部按用户要求复用其它工具页的浅色渐变 `page-header-calculator-bg`，系统状态栏、胶囊和底部手势条不重复绘制。

路由 `/pages/search/index` 属于应用主包，作为全局搜索页，不列入工具分类或使用次数统计。首页与分类页原内联搜索替换为统一搜索入口，分类选择和首页常用/最近使用保持独立。

`utils/tool-search.uts` 从 `config/tools.uts` 读取整个工具目录，搜索名称、简称、关键词、摘要、描述、ID及分类。忽略英文大小写，首尾及连续空白归一化；多词按全部命中处理。名称完整匹配/前缀/包含优先，再按关键词、摘要、描述、分类评分，相同分数保持目录顺序。不构造用户输入正则表达式、不需要后端。

输入实时更新结果，搜索按钮和键盘确认收起键盘并保存搜索词；点击历史可重搜，点击结果复用工具导航。未接入的工具显示“待接入”，不虚构可用路由。结果数来自真实数组，全部结果完整渲染，不把设计稿的8个结果或“其余2个”写死。

最近搜索只记录明确提交、历史重搜或点选结果的词，最多10个，大小写无关去重并把最新词置顶。单词最多60字；超长输入保留原文并提示，不截断后存档。清空输入返回初始状态并重新聚焦，清空搜索历史不会影响工具最近使用或累计次数。

历史使用 `STORAGE_TOOL_SEARCH_HISTORY_KEY`，在 `config/constants.js` 中定义。项目异步存储封装读写版本字符串，词经URI编码；写入与清空串行，页面用版本号和卸载标识防止旧异步回调覆盖新状态。读取损坏存档时允许继续搜索，但不会自动覆盖旧数据，用户可明确清空后重试；写入失败显示未保存提示。

静态验收范围：模板/UTS/SCSS解析、导航注册、导入引用、字号及长行/空标签、三状态数据流、历史并发与卸载回调、`git diff --check`。按uniappx规范未启动、编译或运行项目，未执行业务算法测试。
