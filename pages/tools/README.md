# 生活计算工具

三个工具均在本地计算，不调用后端，也不上传用户输入。入口由 `config/tools.uts` 的 `getToolPath` 统一管理。

- 日期差：使用公历日期编号计算绝对天数；相同日期为 0 天，闰年按公历规则处理。小时数为天数乘 24，并非跨夏令时时段的实际流逝小时数。
- 时间计算：两组非负整数字段先统一转成秒，支持相加、相减；分秒自动进位，小时不按 24 归零。每项最多 9 位，计算保持在整数精度范围内。
- 单位换算：配置在 `config/units.uts`，线性比例统一换算；温度以开尔文为基准处理偏移。数值支持负数、小数及科学计数法，不允许温度低于绝对零度。
- 使用记录：只保存工具 ID 与打开时间，最多保留 20 个工具，不保存计算输入。首页、收藏页的最近使用以及我的页清理记录共用该记录。
