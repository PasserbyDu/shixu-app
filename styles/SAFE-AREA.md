# 页面底部安全区

当前37个已注册页面已逐项静态检查（包含新增的随机点名与图片取色）。此前大多只有固定rpx留白，不能代表设备手势导航区；关于页末尾文字有相同风险。现在统一在内容后追加安全区，不修改业务逻辑。

| 页面范围 | 接入位置 |
| --- | --- |
| 首页、分类、收藏、我的 | 主纵向滚动容器末尾；原生TabBar已占位时框架安全区变量为对应页面剩余安全区，不再额外增加TabBar高度 |
| 搜索 | 页面根容器底部保留安全区，缩小搜索内容区域，同时覆盖历史、搜索结果和空结果三种状态 |
| 关于、分享、反馈 | 末尾说明文字之后、滚动容器内部 |
| 日期差、时间计算、单位换算 | 主滚动容器末尾 |
| 图片转PDF、PDF合并、PDF拆分、文本整理、图片压缩、图片转格式、图片取色 | 主滚动容器末尾，保留内部结果预览的滚动行为 |
| 数字2048、华容道 | 页面主滚动容器末尾，不向棋盘内或关卡弹窗添加重复占位 |
| 其余17个工具页，包括房贷/车贷与随机点名 | 公共tool-page容器末尾统一接入，替换原来的固定40rpx占位；无需各页面重复添加 |
| 级联选择器 | 底部面板复用同一公共安全区样式，替代单独的env声明 |

`styles/common.scss` 由全局入口导入。`safe-area-bottom` 仅追加页面底部安全区；`safe-area-bottom-pad` 同时增加24rpx常规留白。样式依次提供基础值、constant、env和框架安全区变量，不把手势区写死为某个像素高度。末尾占位禁止收缩，必须位于主滚动内容内部；搜索页则通过根容器占位保留真实可视区域。

框架变量 `--uni-safe-area-inset-bottom` 随页面处理原生导航及Web模拟TabBar差异；不能直接把设备物理安全区再加一次到原生TabBar之上。参见[DCloud安全区变量说明](https://doc.dcloud.net.cn/uni-app-x/css/common/function.html#var)。后续新增普通工具页优先使用tool-page，独立滚动页在主内容末尾使用相同占位。

本次仅进行模板、脚本、样式、引用及页面覆盖静态检查，未启动项目、编译或进行设备运行验证。
