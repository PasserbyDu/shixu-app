# 图片转格式

设计来源：[Figma 126:95](https://www.figma.com/design/UQoyHz02FJeU7jbvglW0jG/?node-id=126-95)，P38 图片转格式，390×844。连接器额度受限后通过Chrome查看整页。主要模块约为：标题和说明0—158；本地处理提示170—210；选择图片226—364；格式和尺寸设置384—548；转换按钮570—618；结果和保存640—776；页尾说明约796。按750/390换算，复用 `document-tools.scss` 和现有渐变头部；长文案自然换行，描述不小于20rpx。

页面 `/subPackages/image/image-format` 放在图片工具分包；沿用目录已有工具 ID `image-format`，统一补充路由，自动接入分类、搜索、收藏和使用记录。没有填入设计稿里的演示照片、3.8MB或6.2MB数据。

## 功能

- 单图选取、缩略图预览、重新选择；读取真实格式、体积与像素尺寸，选择取消保留之前的有效结果。原生端复用 `utils/local-media.uts`，网页端补充选择器文件元信息，不修改已有图片压缩逻辑。
- JPG、PNG及受平台支持的WebP编码，默认PNG。保持原尺寸默认开启；关闭后可选择最长边上限，按比例缩小且不放大原图。
- 限制输入20MB、5000万像素，输出最长边4096、像素总量1600万以内。保持原尺寸超限时明确提示关闭开关缩小，不偷偷改变原图尺寸；关闭开关后同时按最长边和像素总量等比缩小。
- 转换使用 `uni.createCanvasContextAsync`、`createImage` 和2D绘图。PNG保留透明通道；JPG先铺白底后绘图。JPG/WebP使用0.92编码质量，不保证文件体积缩小，也不会恢复源图已有的压缩损失。
- 各端统一从新版Canvas位图调用 `toDataURL`，原生及小程序写入本机临时文件，网页保留数据URL。检查编码返回的MIME，防止不支持WebP时回退为PNG却显示转换成功；输出后检查实际格式、尺寸和体积。
- App/小程序保存到相册；网页通过结果预览由用户长按或图片菜单保存。显示的输出名称按选图名称更换后缀，相册实际名称由系统管理。
- 修改图片、格式或尺寸立即清除旧结果。选图、转换和保存互锁；页面退出取消图片加载及绘制帧等待、处理迟到回调，释放画布并清理本页生成的临时文件；不删除用户选择的原文件。保存进行中退出时等待保存返回再清理。

## 平台边界

所有图片留在本机处理，无上传或后端接口。iOS和小程序原生路径不提供WebP导出，该选项保留位置但明确标为不可用；Android、鸿蒙和网页仍以实际编码返回结果为准，不用改扩展名伪造格式。若要求所有平台完整导出WebP，需要额外的本地编码插件或后端转换服务。

仅处理静态画面、不保留动画；输出经过重新编码，不保证保留EXIF及其它文件元数据。权限取消、解码失败、超时、尺寸过大、编码回退、写入失败和相册权限失败均有提示。

## 导出失败修正

旧版小程序分支单独调用 `canvasToTempFilePath`，混合传入canvasId、Canvas节点与null组件参数；画布还位于滚动内容末尾，固定移出屏幕并设为透明，绘制后也没有等待宿主渲染帧。所有该分支原始失败都被改成“请降低尺寸后重试”，因此不能用此提示认定图片过大。

通过只读检查现有小程序产物与本地HBuilderX SDK，确认新版CanvasContext提供原生Canvas节点及直接编码委托。现在统一直接编码位图并写文件，移除该额外导出调用；画布保持在根容器可视区域，独立于滚动内容，无透明/隐藏样式。2rpx仅为展示尺寸，编码尺寸始终按目标像素设置。绘制后等待两个帧回调再编码，设置超时并在卸载时取消等待。编码异常和文件写入失败保留具体信息，不再把所有失败归因于尺寸。

API依据：[CanvasContext](https://doc.dcloud.net.cn/uni-app-x/api/create-canvas-context-async.html)、[UniCanvasElement](https://doc.dcloud.net.cn/uni-app-x/api/dom/unicanvaselement.html)。以上为源码与SDK静态定位，未声称真机复现。

按uniappx技能只做静态自查：模板、UTS、SCSS、条件编译分支、路由与导入、字号、异步状态和临时文件归属、`git diff --check`。未启动、编译或运行项目，未执行图片转换测试。后续运行应覆盖透明PNG转JPG、JPG转PNG、WebP支持/不支持分支、保持/缩小尺寸、原尺寸超限、保存和权限拒绝、选择取消、处理中返回。
