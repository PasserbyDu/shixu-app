# 办公工具分包

页面注册在 `pages.json` 的 `subPackages/office`，工具入口由 `config/tools.uts` 的 `getToolPath` 统一维护。
图片压缩的主归属为图片分类，存放在 `subPackages/image/image-compress.uvue`；办公分类中同一工具复用该路由。

## 设计与实现

设计稿均为 390×844，按照 `750 / 390` 换算 rpx。系统状态栏、胶囊、底部手势条由平台提供，不重复绘制。
原有要求中所有描述文字不小于 20rpx，因此说明文案使用 22–24rpx，卡片随内容自然增高，不强制卡死到设计高度。
文件从空状态开始；图中演示的文件名、缩略图、页数和大小不作为真实业务数据使用。

## 本地能力与限制

| 能力 | 微信小程序 | Android / iOS / 鸿蒙 App | Web |
| --- | --- | --- | --- |
| 文本整理、复制 | 已接入 | 已接入 | 已接入 |
| 图片压缩、保存相册 | 已接入平台 API | 已接入平台 API | 未接入：当前跨端压缩 API 不支持 |
| 图片转 PDF、合并、提取 | 已接入离线 PDF-LIB | 未接入：需 UTS 原生 PDF 插件 | 未接入：需文件选择、导出适配 |
| PDF 保存、分享 | 本地副本 + 微信文档预览菜单 / 文件分享 | 随 PDF 插件适配 | 随文件导出适配 |

上述“已接入”指实现与静态数据流接通，不代表已完成平台运行验收。
本次没有新增后端接口，不上传用户文件或文字；原生端 PDF 也可以通过本地插件实现，无需强制使用后端。
PDF JavaScript 引擎只在 `MP-WEIXIN` 条件编译分支导入，原生端不会导入这份 JavaScript 引擎。
不支持的平台在页面说明中明确标识，操作时给出原因，不展示伪造结果。

- PDF：图片最多 9 张；合并最多 12 份；输入总计不超过 30 MB、200 页。图片只接受 JPG/PNG，单张不超过 2400 万像素。
- PDF：不支持加密文件，不保证交互表单、签名与文档级元数据保真。照片若依赖 EXIF 旋转或镜像，会提示先保存为正向图片，避免生成方向错误。
- PDF：选择、排序、移除、参数修改会使旧结果失效；处理中锁定输入和导出，避免保存过期结果。关闭页面会清理工具生成的临时 PDF，用户主动保存的副本保留。
- PDF：保存按钮先创建本地副本并打开文档预览，用户可从微信预览菜单保存或转发；文件分享需当前微信支持 `shareFileMessage`。不等同于直接写入手机公共下载目录。
- 图片压缩：质量参数仅对 JPG 有效的端上，PNG 可能无法缩小；结果不小于原图时保留原图，不显示虚假压缩率。单张上限 20 MB。
- 文本：最多 50,000 字符，不缓存输入内容；去重保留首次出现的整行及顺序。关闭全部选项保留原文；不执行语义改写。

## 静态检查与待运行验收

按照 uniappx 技能，本次仅检查模板/脚本语法、路由、依赖路径、事件数据流、条件编译隔离与差异；没有启动项目、编译或进行真机联调。

| 待验收场景 | 预期结果 |
| --- | --- |
| 首页图片压缩、分类办公/图片中的图片压缩、收藏同一工具 | 均打开 `subPackages/image/image-compress` |
| 选择 3 张横竖混合图片，拖动第 3 张到第 1 张 | 按最终排序生成 3 页；A4 自动方向逐页决定；图片等比完整显示 |
| 选择 JPG、透明 PNG | 正确生成 PDF；PNG 保留透明区域；HEIC/WebP 明确提示不支持 |
| 选择带 EXIF 旋转的照片 | 提示相册编辑并另存，不生成方向错误的 PDF |
| 合并 8 页、2 页、2 页文档，并上移/移除文件 | 结果按列表顺序生成；页数来自文件解析并实时重新统计 |
| 文件取消选择、加密、损坏、总大小/页数超限 | 取消无误报；其它情况显示明确错误，不生成假结果 |
| 12 页文档输入 `1-3, 5, 8-10` | 生成 7 页新文档；原文件不变 |
| 输入 `5,1-3,3` / `0` / `13` / `5-2` / `1,,2` | 分别为按原顺序的 4 页 / 明确校验错误 |
| 单页模式输入 `3` / `1-3` | 1 页新文档 / 校验错误 |
| 更换文件、修改范围、切换模式、修改纸张 | 清除旧生成结果，重新计算后才能导出 |
| 生成时离开页面、重复点生成/保存/分享 | 不重复处理；生成结束后的临时文件被清理；不更新已销毁页面 |
| 保存、分享取消、微信版本不支持、空间不足 | 取消无误报；不支持/失败明确反馈；成功时可以预览/转发实际文件 |
| JPG 质量 70、PNG、压缩后变大 | 真实文件大小及比例；PNG 提示差异；变大时保留原图 |
| 拒绝相册权限、再次选择图片、改变质量 | 给出权限提示；新输入使旧压缩结果失效 |
| `周一 整理项目资料\n\n周二 完成页面设计\n周二 完成页面设计\n周三 校对交付文档` 开启全部选项 | 从 5 行整理为 3 行，内容顺序不变 |
| 全空白、混合 CRLF/CR/LF、四项全部关闭 | 空结果有说明且不能复制空内容；统一换行按选项生效；全关保留原文 |
