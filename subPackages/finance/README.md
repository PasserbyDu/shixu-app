## 计算口径

- 等额本息：以月利率折现各期本金，得到固定月供；采用折现项求和，避免极小利率下直接相减损失精度。与 `P × r / (1 - (1 + r)^(-n))` 等价。
- 等额本金：每月本金按分取整，按期初剩余本金计算利息；显示首月还款及末月还款，不能当作固定月供。
- 金额以整数分累计，每期利息四舍五入，末期结清剩余本金。明细中的月供、本金、利息、余额与汇总使用同一数据，不以设计稿示例数字代替计算。
- 组合贷分别输入商贷、公积金金额和利率，分项计算后逐期汇总，共用期限与还款方式。两类利率分别保留，切换类型不会覆盖输入值。
- 车贷首付按分取整，贷款等于车价减首付；支持 0% 首付及 100% 全款。全部模式支持零利率。
- 房贷期限为 1—30 年，车贷为 1—7 年；金额上限为每项 100000 万元，年利率 0—100%，输入最多 6 位小数。利率均为可编辑示例，不代表当前银行报价。
- 不包含提前还款、利率重定价、日息、保险、税费、手续费及特殊合同计息规则，无服务端请求。

公式参考：[中国人民银行关于规范住房金融业务的通知（住房公积金中心转载）](https://gjj.tl.gov.cn/tlszfgjjglzx/c00052/pc/content/content_1683847397905199104.html)。
