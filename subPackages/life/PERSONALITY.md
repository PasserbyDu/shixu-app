# INFP 性格测试 · 四维趣味探索

入口在生活工具，工具 ID `personality`，页面 `/subPackages/life/personality`。首页、答题、结果使用同一页面内的三种状态，退出与重测采用公共 `app-dialog`，不是五个互相依赖的路由。搜索、收藏、最近使用与常用工具沿用统一目录。

## 设计与资源

浏览器已读取用户指定的五个节点：`148:25` 首页（390×1020）、`148:92` 答题（390×844）、`148:143` 结果（390×1250）、`260:218` 退出、`260:280` 重测。Figma MCP 提供了首页、答题与重测的设计上下文，结果和退出节点触及调用额度后以浏览器继续核对。

模块按 750/390 换算：主内容左右各 38rpx、卡片圆角约 30rpx、英雄区圆角 38rpx、按钮最低 88rpx、标题 46rpx。设计中的9px小字调整为至少20rpx。整体淡蓝头部、薄荷绿至淡蓝的插画/结果区、四维度绿/蓝/紫/金配色。正文使用正常流 flex，长题与长结果可滚动，末尾复用安全区。

首页插画直接引用用户提供的 `https://i.postimg.cc/RFj61b2q/infp.png`，图片包含背景、插画及底部说明，以674×578rpx等比完整展示，不再下载或打包首页插画。首页整体使用薄荷绿至淡蓝渐变背景，结果枝叶使用 view 配合 CSS 边框、圆角和旋转近似绘制，不依赖图片。系统状态栏、微信胶囊使用平台已有能力，进度条、卡片和按钮使用原生布局。

## 网络资料与许可

- [IPIP 官网及公共领域授权](https://ipip.ori.org/)：条目和量表可以复制、编辑、翻译，也可商业使用。
- [IPIP Big-Five Factor Markers 条目](https://ipip.ori.org/newBigFive5broadKey.htm)：本工具题目 `source` 字段对应阅读到的英文条目；中文为情境化改编，不声称是已验证的中文译本。
- [IPIP 正反向计分](https://ipip.ori.org/newScoringInstructions.htm)：采用1—5计分，反向项为6减原分。
- [Myers & Briggs Foundation 四偏好与16类型介绍](https://www.myersbriggs.org/my-mbti-personality-type/the-16-mbti-personality-types/)：仅参考四字母框架及类型概念，结果称谓、建议为本工具自行撰写；INFP 的示例标题、标签和共鸣文案来自用户设计。

没有复制商业 MBTI 题库，也没有采用带非商业限制的 OEJTS 题库。重要区别：IPIP 大五人格条目不是 MBTI 四维量表；本工具借用相关条目探索 I/E、N/S、F/T、P/J，自行编成24题，每维度6题、正反各3题。尤其宜人性与尽责性不能被视作 F/T 与 P/J 的等价测量。本工具无常模、无效度承诺，不用于诊断、职业筛选或能力判定。页面与导出的图片均标注趣味探索及非专业评估。

## 计分与状态

- 选项从非常符合到完全不符合对应5、4、3、2、1，0表示未答。所有题完成前不生成结果，上一题保留原答案。
- `direction=1` 直接累加，`-1` 累加 `6-answer`。每维总分6—30，以 `(total-6)/24` 换算左侧倾向，右侧为补数；这不是概率、人群百分位或置信度。
- 总分高于18取左字母，低于18取右字母，等于18显示 X，说明该维度倾向不明显。16种非同分组合均有对应画像；含 X 时使用开放的均衡文案，不强行给出 INFP。百分比、类型、标签及卡片均来源于同一次计分。
- 退出弹框显示实际已答数量；继续/X/遮罩仅关闭弹框，退出才清空本次答案回到介绍页。重测取消保留结果，确认后清空并回到第1题。
- 自定义返回入口和支持 `onBackPress` 的端会在答题中提示确认；微信原生页面返回/手势不支持这类拦截时，页面卸载直接清空内存，不声称可以拦截系统手势。
- 不保存答案或结果，不读取个人信息，答题与计分在本机完成；首页插画通过网络加载，不传输答案或结果。记录工具打开次数只沿用已有使用统计。

## 卡片与分享

点击保存后使用页面根部的原生2D canvas 绘制750×1280 PNG，等待绘制提交后编码。App与小程序写入本工具临时文件并调用已有 `saveLocalImage()`；Web使用图片预览与图片菜单保存。失败保留结果、允许重试，不把复制文字当成图片保存。离开后清理本工具临时 PNG；主动写入相册的图片由用户管理。

微信分享注册在页面脚本，使用 `createPageShare`、`createTimelineShare` 和 `showPageShareMenu`，只分享页面入口，不包含答案或结果参数，也不指定 logo 封面，按项目规范使用当前页面预览。
