# 分享给朋友

- 入口：我的 → 更多 → 分享给朋友；页面位于本分包 `share.uvue`。
- 微信小程序采用原生 `button open-type="share"`，由用户在微信面板选择好友或群聊；按钮分享首页 `/pages/index/index`。该页右上角菜单分享当前分享说明页。不用点击事件模拟分享，不提示“分享成功”，也不自动发送消息。
- App、网页没有配置微信分享SDK，按钮点击提示前往微信小程序，不调用不可用的SDK。
- 当前没有可直接打开小程序的有效链接，按用户要求移除复制按钮、菜单指引、剪贴板逻辑及空链接配置。只保留真实的小程序卡片分享。
- 头部复用工具页 `page-header-calculator-bg` 浅蓝背景与深色文字。Logo使用用户提供的HTTPS图片，按原比例显示。页面关键字号、留白、居中采用局部SCSS，避免依赖现有小程序样式产物中缺失的工具类。
- 分享按钮的视觉容器固定96rpx高，原生分享按钮覆盖整个点击区域，避免原生按钮默认内边距影响排版；外层点击不模拟微信分享。
- 仅完成静态检查，未进行编译、页面运行或真机分享验证。

官方依据：[uni-app x页面分享事件](https://doc.dcloud.net.cn/uni-app-x/page.html#onshareappmessage)、[分享说明](https://uniapp.dcloud.io/api/plugins/share)。

## 全页面统一分享

全部 37 个注册页面均显式注册 `onShareAppMessage` 和 `onShareTimeline`，并在加载时通过 `showShareMenu` 打开好友/群聊、朋友圈菜单。使用页面中的生命周期声明，便于微信小程序编译器识别分享能力，不依赖组件内 hook 或运行时全局混入。

`utils/page-share.uts` 统一生成标题、页面路径和朋友圈参数，`config/share.uts` 管理首页文案。好友卡片直达当前页面；朋友圈由微信进入当前页面，查询参数显式为空。不设置 `imageUrl`，不使用 logo 或自定义封面，由微信默认生成当前页面预览。

分享链接只含页面标题和固定入口，不附带生日、名单、文件等输入或日期选择会话 token。接收者打开页面后看到自己的本机数据或页面默认状态；农历选择页无 token 时按独立日期工具打开。分享预览由微信生成，可能包含当前页面可见内容。

仅 `MP-WEIXIN` 分支启用这些事件和菜单；App、Web 保留既有行为，未配置微信 SDK 时不伪装分享成功。朋友圈的最终可用性由微信客户端及平台规则决定。新增页面须同步接入同一套声明，静态检查以 `pages.json` 为覆盖清单。
