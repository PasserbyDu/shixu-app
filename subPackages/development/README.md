## 复用及状态

- 顶层 `tool-page` 提供头部及滚动结构；本分包 `source-editor`、`format-result` 分别复用两页的输入操作和行号结果；跨页样式位于 `styles/developer-tools.scss`。
- 工具定义、分类及路由统一在 `config/tools.uts`；路由注册在 `pages.json` 的 `subPackages/development`。原有 JSON、代码工具 ID 保留，新增 `radix`，首页、收藏等旧 ID 入口一并可用。
- 输入或选项变化后立即废弃旧结果；复制及压缩会检查当前结果状态。粘贴只由按钮主动触发，超过长度限制不会覆盖原文；等待剪贴板期间若编辑或切换设置，迟到的响应不会覆盖新内容。离开页面后忽略剪贴板回调。
- 原生输入框不截断文本或整数，由处理函数校验长度，避免超长数字被截断后变成另一个有效数字。长结果每次展开 200 行，复制始终包含完整结果；结果文本使用 `white-space: pre-wrap` 保留缩进并允许长行换行，见[官方空白处理规则](https://doc.dcloud.net.cn/uni-app-x/css/white-space.html)。
- 仅记录工具使用 ID，不存储输入内容，不上传，不使用 `eval`、`Function`、DOM 或浏览器专用 API，无新增依赖或后端接口。

## JSON

`utils/json-format.uts` 以词法扫描及显式容器状态栈校验标准 JSON，支持对象、数组、根标量、转义、Unicode 和指数数字，拒绝注释、单引号、尾随逗号、非法数字及多根值。错误显示原文行列位置；CRLF 按一次换行计数，列按 UTF-16 代码单元计数。

排版及压缩直接使用已校验的原始 token，不进行 `JSON.parse` → `JSON.stringify`，因此不会将超过浮点数安全范围的整数、指数数字、负零或高精度小数重新序列化。保留键顺序、重复键及字符串转义字面量；重复键在不同消费端可能有不同解释，本工具不合并键。

支持 2/4 空格缩进、复制、压缩；压缩从原始输入重新校验后去除结构外空白，字符串中的空格保留。最多 20,000 字符、200 层嵌套，输出超过 400,000 字符会提示分段处理。

## 代码排版

`utils/code-format.uts` 是 UTS 实现的保守排版器，不是完整编译器或 Prettier：

- JavaScript 根据词法片段调整括号/块缩进、分号和常见运算符空格，保留原有换行以避免随意改变自动分号插入规则。字符串、模板字符串、注释、正则字面量保持原文；支持指数数字、BigInt 字面量和转义标识符。输出前重新扫描并对照 token 及原有换行边界，避免运算符合并或数字字面量变化。对不能安全识别的正则/除法组合等情况报错，原文不变。JSX、TypeScript 不属于此页支持范围。
- CSS 调整块与声明换行及缩进，保留选择器、字符串、转义字符、函数参数及其内部空白，不执行选择器或声明。不是 CSS 完整语法验证器。
- HTML 按常见块标签调整缩进，保留内联相邻标签间的文本/空格及属性引号内容；`pre`、`textarea`、`script`、`style`、`title` 的内容原样保留，不继续格式化嵌入代码。不进行浏览器的完整 HTML5 语法纠错。
- 成功状态为“处理完成”，不标记“语法校验通过”。应在运行任何代码前由项目自己的编译器/检查器验证。普通排版可在各目标端本地完成，无需后端。

同样限制 20,000 字符及最多 200 层结构、400,000 字符输出；模板字符串嵌套最多 50 层。示例按钮使用当前语言对应示例，切换语言保留用户原文。

## 进制

`utils/radix.uts` 用小整数位数组逐位乘加，不使用 `Number` 或 `parseInt` 表示整个数值，也不依赖各平台的 BigInt 支持。支持 2/8/10/16 进制、最多 512 位输入、正负号、大小写十六进制、对应进制的 0b/0o/0x 前缀；拒绝小数、指数表示和不属于输入进制的字符。去除前导零，将负零规范为 0；十六进制输出大写。

负数使用符号加绝对值表示，不是固定字长补码。二进制显示从右起每 4 位分组，逐行复制使用无分组空格的原始结果。切换输入进制保留输入，清除旧结果并要求重新换算。

## 自查与后续运行验收

本次按 uniappx 规范只做静态自查：模板、UTS 语法解析，样式语法、组件事件、导入、路由、字体下限、差异空白检查；没有启动、编译项目或执行算法测试。

后续运行可核对：

1. JSON 示例输出 4 行，2/4 空格切换；压缩后字符串中的空格保留；`{"n":9007199254740993}` 保留原整数；根值 `false`、`null`、`0` 均可处理。
2. JSON 的尾随逗号、缺冒号、非法转义、未结束字符串、前导零、两个根值应报出原文行列，不能复制旧结果。
3. JS 示例输出三行；检查指数数字 `1e-3`、注释、转义字符串、正则、模板字符串、`return` 后原有换行及 `for (;;)` 的分号；CSS 的 `calc()`/URL/注释与 HTML 的内联空格、引号内 `>`、预格式区域不应丢失。
4. 255 的结果为二进制 `1111 1111`、八进制 `377`、十进制 `255`、十六进制 `FF`，复制二进制为 `11111111`；负数、前导零、前缀、超大整数及非法字符有对应处理。
5. 清空、粘贴失败、超长粘贴、粘贴时继续编辑、设置变化、页面返回后的复制/粘贴状态均需在目标端验收。
