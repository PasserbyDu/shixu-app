# 聚会摇骰子

设计：[75:2113](https://www.figma.com/design/UQoyHz02FJeU7jbvglW0jG/?node-id=75-2113)，390×844。分类为 games，工具 ID 为 `party-dice`，路由 `/subPackages/games/party-dice`。

页面按原稿顺序实现骰子数量（1—6 颗）、蓝色骰盘/轮次/状态、点数合计/开盅控制、再摇一次、音效开关和说明。骰子用业务组件 `dice-face` 的九宫格点阵实现，1 点为红色，其余为蓝色；没有用整张图片替代控件。

## 行为

- 状态为 `idle → rolling → covered ↔ revealed`。每颗骰子独立用 `Math.floor(Math.random() * 6) + 1` 抽取，最终结果只抽取一次；动画中的临时点数不覆盖结果。
- 约 850ms 后落骰并自动盖盅。90ms 的动画计时器和截止时间同时保护动画结束，只会结算一次；摇动时禁止重复摇骰和切换数量。
- 盖盅隐藏骰面、单颗点数文字及点数合计；开盅才展示。同一轮反复盖盅/开盅不会重新随机。切换数量清空上一轮结果，下一次摇骰增加轮次。
- 页面隐藏时停止计时器和音效，未完成摇动直接结算为盖盅，已开盅也会重新隐藏；返回后不自动播放。卸载时销毁音频上下文。
- 初始未摇骰，显示“准备开始/等待摇骰”，没有将设计稿的“第3轮/17点”当作真实记录。

## 音效

`static/audio/dice-roll.wav`（约0.72秒）与 `dice-land.wav`（约0.18秒）为本次生成的原创单声道 PCM 音效，22050Hz/16bit，不依赖远程音频或后端。以 `/static/audio/...` 绝对路径交给 [`uni.createInnerAudioContext`](https://doc.dcloud.net.cn/uni-app-x/api/create-inner-audio-context.html)，设置 `obeyMuteSwitch = true`，只在用户点击摇骰后播放，关闭开关立即停止。

音效开关用项目存储封装保存，key 统一在 `config/constants.js`。播放失败会提示但不影响骰子结果；实际静音策略及音频播放需在目标平台验收。随机算法为普通聚会用途，不宣称密码学随机或服务端可审计。

## 验证范围

仅做模板/UTS/SCSS 语法解析、生命周期和状态流静态复核、路由与路径核对、字体下限、WAV 文件头/非空检查及 `git diff --check`；没有运行、编译项目或执行算法测试。

后续运行应检查每种数量、1—6 点阵、合计范围 `n..6n`、快速连点、摇动中切后台、开盅/盖盅无泄露、换数量、静音/音效开关、音频失败和退出后的计时器清理。
